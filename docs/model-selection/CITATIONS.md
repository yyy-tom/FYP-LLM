## 11. How to Use These Citations

### In-Text Citations (APA Style)

**For a single author:**
- (Hendrycks et al., 2021)
- Hendrycks et al. (2021) found that...

**For multiple authors (3-5):**
- First citation: (Hu, Shen, Wallis, et al., 2021)
- Subsequent citations: (Hu et al., 2021)

**For organizations:**
- (OpenAI, 2023)
- (Anthropic, 2024)

**For websites without authors:**
- (OpenAI, 2024)
- Use organization name as author

### Reference List Format

All references should be listed alphabetically by first author's last name at the end of your document. Use hanging indent format:

```
Author, A. A., Author, B. B., & Author, C. C. (Year). Title of article. 
    Journal Name, Volume(Issue), Pages. DOI or URL
```

### Example Reference Entry

```
Hu, E. J., Shen, Y., Wallis, P., Allen-Zhu, Z., Li, Y., Wang, S., 
    Wang, L., & Chen, W. (2021). LoRA: Low-Rank Adaptation of Large 
    Language Models. arXiv preprint arXiv:2106.09685. 
    https://arxiv.org/abs/2106.09685
```

## 12. Notes on Citation Accuracy

1. **Benchmark Scores:** All benchmark scores (MMLU, GSM8K, CMMLU, etc.) should be cited from the official leaderboards or model cards. Verify current scores as they may be updated.

2. **Pricing Information:** API pricing changes frequently. Always check the official pricing pages and include the retrieval date in your citation.

3. **Model Specifications:** Technical specifications (parameters, architecture, context length) should be cited from official model cards or technical reports.

4. **Privacy Incidents:** Cite from official announcements or reputable news sources. Include dates for accuracy.

5. **ArXiv Preprints:** When citing arXiv preprints, note that they are not peer-reviewed. If a peer-reviewed version exists, cite that instead.
